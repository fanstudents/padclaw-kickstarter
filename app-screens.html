APP 介面與功能細節總覽

PadClaw 裝置端軟體的 18 個核心畫面，以純 UI mockup 呈現（規劃中軟體 · planned software）。設計語言分兩層：瀏覽型畫面比照 Netflix／Apple tvOS（billboard 大看板、shelf 卡列、焦點放大＋高光的 focus model、毛玻璃 chrome），任務型畫面維持深炭底、品牌綠 #05CE78、超大字級的單任務設計（senior-friendly）。安全模型：大腦／手分離——AI 只收到任務，憑證與檔案永遠留在本機安全晶片與自有機房。

Principles

一屏一事每畫面只有一個主要動作；永不出現第二層選單
克制的綠accent 僅用於主要動作、焦點環、正向狀態
夜間模式整體降至 30% 亮度、白色偏琥珀、禁用純白
可及性觸控目標 ≥ 56px；所有狀態同時以圖標＋文字表達（不依賴顏色）
語氣介面文案對人說話（"Emily will see this"），不用系統腔（"Sharing enabled"）
SECTION 01

系統核心

開機、導航、語音、夜間、隱私——五個構成整個系統骨架的畫面。原則：永遠不出現超過一層的選單。

Core 1/6 · 首次開機

Welcome — 唯一的設定畫面

  • 一句話設定：插電後顯示「Hi, Barbara!」與單一按鈕「Say hello to begin」，說一聲哈囉即完成啟用
  • 零帳號流程：姓名、提醒、家人連結皆由送禮者事先於出貨前配置
  • 畫面上永遠只有一個可按的東西——這是全系統的設計基調
Core 2/6 · 主畫面

Channel Launcher — Billboard＋Shelf 首頁

  • Billboard 大看板（上 55%）：當下最相關的內容當主角——早晨即天氣簡報，scrim 上承載 FEATURED 標籤、標題與 Open 主按鈕
  • YOUR CHANNELS shelf：四張作品級橫卡，焦點卡放大＋白色高光邊＋鄰卡降暗（tvOS focus model）
  • 毛玻璃頂部 tab 列：Home／Channels／Family／Settings＋個人頭像
  • COMING SOON 列於畫面底緣露出一角——暗示可下捲，未來頻道 OTA 免費解鎖
Core 3/6 · 焦點狀態

Focus State — 焦點互動示範

  • 焦點移到 Horoscope：卡片放大 112%、白色高光邊、深柔陰影、藝術圖上有 parallax 光澤掃過
  • metadata 浮現：焦點卡下方出現「Today for Leo · 2 min read」與綠色底線
  • 環境反應：背景 ambient glow 隨焦點內容轉為暖金色、billboard 降暗讓位——與 tvOS 行為一致
  • 此畫面供設計師理解互動規格，非獨立頁面（註：草稿中 billboard 溫度誤為 °C，正式稿一律用 °F）
Core 4/6 · 語音

Voice Overlay — 跨房間語音

  • 遠場收音：雙麥克風陣列，煮菜時隔著流理台喊即可
  • 即時逐字稿：大字顯示聽到的話（「What should I wear today?」），長輩能確認它聽對了
  • 綠色波形＝正在聽的唯一狀態指示，說完自動執行並退回原畫面
Core 5/6 · 夜間模式

Night Mode — Tomorrow 簡報

  • 日落後自動降到耳語亮度，色溫轉暖、藍光最小化
  • 一張卡看完明天：天氣、第一個行程、要記得的事
  • 鬧鐘＋助眠音一併確認；主人關燈後螢幕自動全暗
Core 6/6 · 隱私

Sharing & Privacy — 尊嚴設計

  • 被分享者看得到分享內容：「What Emily can see」逐項列出，Everything else 永遠標示 Never shared
  • 一鍵停止分享：大型 Stop sharing 按鈕，不藏在子選單
  • Delete all my data：一鍵同時清除裝置與伺服器資料
SECTION 02

Family Health 頻道

三個畫面完成一個閉環：提醒 → 簽到 → 家人放心。非醫療器材，僅提供提醒與一般資訊。

Health 1/3 · 頻道首頁

Morning Medications — 用藥清單

  • 超大字用藥卡：藥名＋劑量＋巨型圓角勾選框，勾選即回報完成
  • 下一件事卡：如「Blood pressure reading at 9:00」，時間到會語音輕聲提醒
  • Today／Reminders／History 三個大分頁，歷史紀錄供回診時參考
Health 2/3 · 每日簽到

Daily Check-in — 一顆按鈕

  • 半個螢幕大的綠色按鈕「I'm OK today」——整個功能的核心互動
  • 透明告知：按鈕上方明示「Emily will see this」，簽到是長輩主動的行為
  • I need help 次要連結：通知指定家人（非緊急救援服務）
  • 錯過簽到時：先語音提醒本人兩次，仍無回應才通知家人
Health 3/3 · 完成狀態

All Done — 完成回饋

  • 大打勾＋「All done, Barbara!」：明確的完成感與正向回饋
  • 「Emily can see you're OK ✓」：連結感——這一下按的是給女兒的安心
  • 順帶一句今日建議（「72° Sunny — great day for a walk」），把簽到變成愉快的小儀式
SECTION 03

Horoscope 頻道

不是罐頭運勢——輸入一次出生資料，每天以真實星盤運算生成個人化讀本。

Horoscope 1/2 · 一次性設定

Your Birth Chart — 星盤建檔

  • 三張輸入卡：生日／出生時間（可略）／出生地，填一次終身使用
  • Create my chart 單一動作按鈕，即刻運算本命盤
  • 資料僅用於星盤運算，適用一鍵刪除
Horoscope 2/2 · 每日讀本

Today for Leo — 串流級頻道頁

  • 全幅星空 billboard：金線星盤藝術圖佔滿背景，右側黑色 scrim 承載內容——像串流平台的作品頁
  • metadata 列：「May 24 · ☉ Leo season · 2 min」，閱讀時長比照影片時長的資訊習慣
  • 毛玻璃讀本卡 × 3：Career／Love／Energy，20% 透明度＋hairline 邊框＋五星能量指標
  • Read aloud 主按鈕＋「Ask a question」次按鈕：可語音追問「為什麼今天適合談判？」
SECTION 04

Weather 頻道

天氣 app 給數字，PadClaw 給決定：帶不帶傘、穿什麼、幾點出門。

Weather 1/1 · 晨間簡報

Morning Briefing — 電影感全幅天氣頁

  • 實況即背景：整頁是西雅圖雨雲天際線的全幅動態藝術圖——天氣本身就是 billboard（Apple TV 作品頁的資訊結構）
  • 176px 超細體溫度疊在 scrim 上，三公尺外可讀（玄關情境）
  • 毛玻璃行動卡：「Rain at 8 AM — take an umbrella」，把預報翻譯成動作
  • 毛玻璃逐時 shelf（8AM 帶綠色焦點底線）＋通勤卡「Leave by 8:10」＋穿搭卡「Light jacket weather」
SECTION 05

Learning 頻道

孩子端十分鐘一節的練習、家長端的透明報表——在家庭共用螢幕上，不是孩子房間裡的演算法。

Learning 1/3 · 頻道首頁

Subject Picker — 串流級學習首頁

  • CONTINUE LEARNING billboard：像「繼續觀看」——上次的乘法練習配吉祥物藝術圖、72% 進度條與 Continue 主按鈕
  • SUBJECTS shelf：四張直式科目卡（Netflix Kids 的卡列語言），焦點卡放大＋白色高光邊，各帶進度與百分比
  • streak chip 與 Parent view 固定在毛玻璃頂列——家長隨時可看，孩子知道家長看得到；斷 streak 不歸零、不推播羞辱
Learning 2/3 · 練習中

Practice Session — 十分鐘一節

  • 一題一畫面：巨型題目卡＋四個大按鈕，無廣告、無干擾元素
  • Question 4 of 10：節次固定十題，做完就說再見——刻意設計的「有結束」
  • 自適應難度：連對升階、連錯降階並換一種講法重教
  • 星星吉祥物只慶祝、不催促
Learning 3/3 · 家長報表

Parent Report — 每週摘要

  • 三個數字講完一週：節數／分鐘／正確率
  • 每日分鐘長條圖：一眼看出學習節奏
  • AI 重點卡：「乘法開竅了，下週試 Level 4」——給家長可以說出口的鼓勵素材
SECTION 06

Security & Trust

安全模型的三個使用者可見面：行動前的同意閘門、一個開關的隱私路由、全程留痕與一鍵回復。原則——「AI 知道要幫你做什麼，但它從來看不到你的帳密和檔案。」

Security 1/3 · 同意閘門

Approve / Deny — 每個對外動作先問過你

  • 白話文告知三件事：要做什麼（Order this week's groceries）、用哪個模型（PadClaw AI — your private cloud）、資料去哪（your grocery store only）
  • 「Your login stays on this device」明示於卡上——大腦／手分離的使用者語言
  • Approve／Not now 雙大按鈕：預設不做，最後一道把關永遠在人手上
  • 路由判斷偏保守：不確定是否敏感 → 一律當敏感、走自有機房
Security 2/3 · 隱私路由

Where Your AI Runs — 一個開關，不是模型選單

  • 唯一的主開關：「Sensitive tasks only use PadClaw AI」，預設開啟——使用者懂的是隱私等級，不是模型名稱
  • 兩條路白話說明：私人檔案／帳號 → PadClaw AI（台灣自有機房，資料不出門）；一般查詢／寫作 → 最強可用模型（不附個資）
  • Advanced 收合列：工程師可指定模型、帶自己的 API key、調路由規則——藏在進階區，不干擾一般人
  • 底部明示保守原則：「When unsure, PadClaw treats a task as sensitive.」
Security 3/3 · 操作紀錄

Activity — 全程留痕、一鍵回復

  • 人話版稽核日誌：每筆動作＋時間＋執行模型 chip（PadClaw AI／Cloud model），逐筆可 Undo
  • 被擋下的也記錄：「Blocked: unknown website request — Nothing was sent」，安全事件用平常心呈現
  • Restore point：「Restore to yesterday 9:00 PM」一鍵回復——搭配唯讀系統分區與受控備份，誤刪與勒索軟體都拿不走家庭照片
